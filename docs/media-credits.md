# Media credits

Every image shipped in `public/` comes from a public repository owned by
[Arp1tSingh](https://github.com/Arp1tSingh). Nothing here was generated, edited or
upscaled: each file is the byte-for-byte original fetched from the source repository and renamed
to a stable public path.

`public/` is served at the site root, so `public/media/<name>` is the URL `/media/<name>` and
`public/og/og.png` is `/og/og.png`. The `src` values in `content/stops/*.json` are relative and
resolve to those paths.

## Notes

- **Provenance.** `path-tracer.png` and `arpit-landscape.jpg` came from
  `Arp1tSingh.github.io`, whose branch root is published to GitHub Pages. The other six came
  from the project repositories they depict.
- **Attribution.** The portrait and the landscape photograph are of the author. The BillBox
  receipt screens are synthetic fixtures with no real bill, company, account or meter behind
  them, and the RegimetTrader figures come from the project's own backtest reports.
- **Sizes.** Total weight of everything in `public/media/` and `public/og/` is about 1.8 MB, of
  which the two photographs are about 1.4 MB.
- **Excluded.** `BillBox`'s `docs/demo.gif` (4 MB animated walkthrough) is deliberately not
  copied — a static pair of receipt screens carries the same evidence for a fraction of the
  weight.
- **The social card is generated, not downloaded.** `npm run og` writes `public/og/og.png`
  from `scripts/build-og.ts`, with no image library: the PNG is assembled byte by byte and
  `public/og/og.svg` is the editable source of the same design. The previous site's card was
  a different design for a different site, so it is not carried over.
- **Not vendored.** No fonts and no third-party code were copied from these repositories. The
  font files the portfolio uses are installed from npm packages listed in `package.json`.
