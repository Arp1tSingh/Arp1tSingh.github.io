01 About

Full-stack fundamentals,
now pointed at AI.

I started with C and brute-force algorithms, moved through full-stack web, and kept pulling the thread further down — into systems, networking and models that actually do something.

DeepGuard v2

Full-stack deepfake forensics. Upload a video, get a verdict from three independently-verified detectors (UCF, SPSL, Xception from DeepfakeBench), plus Grad-CAM heatmap overlays showing exactly which face regions drove the prediction — per-model signal breakdowns, a temporal confidence timeline, and a downloadable PDF forensic report.

  • Xception
  • FastAPI
  • Next.js
  • Tailwind v4
  • PDF export

Rebuilt solo after a team mini-project. Runs 3 models on CPU with real stage labels, not a fake spinner.

Featured React · TypeScript · FSRS-6

LeetCode Spaced Repetition Tracker

Turns one-off problem solving into a review system. Schedules each problem with the Free Spaced Repetition Scheduler, modelling memory as Stability S and Difficulty D so you review at the exact moment retrievability decays toward target recall.

  • FSRS-6
  • Paced review queue
  • Auto-sync
  • Pattern mastery
  • LocalStorage
  • Spaced repetition

Cold-start overload protection: imported problems are calibrated into a paced queue instead of a day-one wall of 200 cards.

P2P File Sharing

BitTorrent-style transfers between devices on different networks with just a link. No account, no port forwarding, no dependencies — a tracker, a magnet URI and a relay mode that tunnels across NAT. Works from a phone browser with zero terminal.

  • Sockets
  • Magnet URIs
  • NAT traversal
  • Piece hashing

Multithreaded CPU Path Tracer

A physically-based renderer built from scratch. Recursive path tracing with up to 10 light bounces, a bounding-volume hierarchy that takes ray intersection from O(N) to O(log N), and Lambertian, metallic and dielectric materials — all through hand-written ray maths, no OpenGL or DirectX.

  • BVH
  • Ray tracing
  • std::thread
  • SSAA
  • Gamma 2.0
