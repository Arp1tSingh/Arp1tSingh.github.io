03 Work

Nine things I actually shipped.

Each one runs. Every deployment link is live.

DeepGuard v2

Full-stack deepfake forensics. Upload a video, get a verdict from three independently verified detectors — UCF, SPSL and Xception from DeepfakeBench — plus Grad-CAM heatmap overlays showing which face regions drove the prediction, per-model signal breakdowns, a temporal confidence timeline, and a downloadable PDF forensic report.

Rebuilt solo after a team mini-project. Runs three models on CPU and surfaces real stage labels rather than a fake spinner.

Source
Featured ReactTypeScriptFSRS-6

LeetCode Spaced Repetition

Turns one-off problem solving into a review system. Schedules each problem with the Free Spaced Repetition Scheduler, modelling memory as Stability S and Difficulty D so you review at the moment retrievability decays toward target recall.

Cold-start protection: imported problems are calibrated into a paced queue instead of a day-one wall of two hundred cards.

Live app Source
Pythonstdlib only

P2P File Sharing

BitTorrent-style transfers between devices on different networks with just a link. No account, no port forwarding, no dependencies — a tracker, a magnet URI and a relay mode that tunnels across NAT. Works from a phone browser with zero terminal.

Live app Source

CPU Path Tracer

A physically based renderer built from scratch. Recursive path tracing with up to ten light bounces, a bounding volume hierarchy that takes ray intersection from O(N) to O(log N), and Lambertian, metallic and dielectric materials — all through hand-written ray maths, no OpenGL or DirectX.

An infinite-canvas whiteboard for visualising DSA problems. Pan and pinch-zoom freely, four pen types, shapes and text, full undo/redo, autosave to localStorage, and PNG or JSON export. No build step, no dependencies, no server.

04 Journey

How the curve bent.

Dated from actual commit history, not vibes.

October 2025

First blood

Started shipping instead of watching tutorials. A full-stack ERP system split into separate frontend and backend repositories, and a console TSP bus-route solver in C to learn brute force against branch & bound. Twenty-seven commits in three weeks.

  • JavaScript
  • Node.js
  • C

November 2025 — March 2026

A quiet stretch

No public commits for five months. Coursework and reading, mostly — this gap is real and the calendar in the next section shows it. What came out of it was the decision to stop coasting and go lower-level.

April 2026

Down to the metal

Wanted to know what was actually happening underneath, so wrote a multithreaded path tracer in C++ — BVH, recursive bounces, dielectric refraction — alongside a Python OS log analyzer.

  • C++
  • std::thread
  • Python

August 2026

Into the models

Vendored DeepfakeBench and started running real detection checkpoints. Built the LeetCode archive, shipped the first DeepGuard as a team mini-project, and — frustrated with brute-force repetition — designed a proper review scheduler that became the FSRS tracker.

  • Grad-CAM
  • FSRS-6

Five projects in one month. DeepGuard rebuilt solo as a three-detector forensics platform with Grad-CAM evidence. BigOBoard. The E-Waste Passport. The Wishlist Keeper. A fintech committee site. And a BitTorrent-style P2P transfer on the Python standard library alone. One hundred and three commits.
